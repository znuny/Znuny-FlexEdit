Znuny-FlexEdit
=================

**Feature List**

The Znuny-FlexEdit package is an extension for inline editing of ticket attributes in the **Ticket Information** widget of the ticket zoom screen.

Agents can change type, state, lock, priority, queue, service, SLA, owner, and responsible without opening a popup. Several attributes can be edited in one pass and saved together.

[Further information can be found here.](doc/en/feature.md)

**Prerequisites**

- Znuny 7.3

**Installation**

Download the [package](https://download.znuny.org/releases/packages/) and install it via admin interface -> package manager.

**Configuration**

See the available settings in [doc/en/feature.md](doc/en/feature.md#configuration).
